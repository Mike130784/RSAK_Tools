# RSAK Prefab

**In ontwikkeling — nog geen openbare download.**

[Alle tools](../../README.md)

## Waar werkt deze tool naartoe?

RSAK Prefab richt zich op het voorbereiden van uitvoer vanuit prefabsets: sheets, detail- en 3D-views, tags, maatvoering en gefilterde schedules op basis van een passend profiel.

## Waarom nog geen download?

De maker heeft aangegeven dat Prefab nog niet voldoende is ontwikkeld voor openbare vrijgave. Het bestaande 0.2.2-pakket is een ontwikkel-/testpakket en bevat bovendien bronbestanden. Het wordt daarom niet via deze downloadrepository verspreid.

Een geslaagde compilatie of geïsoleerde installatietest verandert die status niet. Eerst moeten de functionaliteit, profielen, isolatie en uitvoer in echte modellen praktisch worden goedgekeurd.

Deze pagina houdt het product zichtbaar zonder een ontwikkelkandidaat als werkende publieke release aan te bieden.
