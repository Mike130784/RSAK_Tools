# RSAK Sheet Exporter

**Sheets en exportinstellingen vooraf overzichtelijk controleren.**

[Alle tools](../../README.md)

## Status: nog geen openbare download

Voor deze tool is nog geen praktische vrijgave bevestigd. Daarom biedt deze catalogus geen installer of portable aan. De bekende P1-baseline is een read-only voorbereiding en controle voor Revit 2025.

## Wat de beschreven P1 kan

Sheets zoeken, filteren en selecteren, bestandsnamen vooraf bekijken, bestaande DWG Export Setups inspecteren en controles uitvoeren op onder meer ISO13567, kleur-/override-instellingen, printbaarheid en bestandsnaamconflicten.

## Wat P1 nog niet doet

Daadwerkelijke PDF- of DWG-export, gecombineerd PDF-bestand en eigen naamgevingstokens horen nog niet bij deze beschreven P1. De productnaam mag niet worden gelezen als een belofte dat de exportengine al beschikbaar is.

Een publieke download volgt pas na een afzonderlijke praktische vrijgave van de bedoelde versie en Revitjaargang.
